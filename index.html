What is HTML?

The basic language used to structure content on web pages.

HTML stands for HyperText Markup Language. It tells a web browser how content is organized, such as headings, paragraphs, images, links, lists, and forms. HTML is a markup language, not a programming language.

How an HTML element is written

<p class="intro">Hello, world!</p>
  • <p> is the opening tag.
  • class="intro" is an attribute that gives the element extra information.
  • Hello, world! is the content.
  • </p> is the closing tag.

Basic HTML document

<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>My First Page</title>
</head>
<body>
  <h1>Hello, world!</h1>
  <p>This is my first webpage.</p>
</body>
</html>
Remember: Some elements are void elements. They do not wrap content and do not need closing tags, such as <img>, <br>, <hr>, <input>, and <meta>.

01. Basic document structure

The essential elements that make an HTML page.

<!DOCTYPE html>

Declares that the document uses modern HTML (HTML5). It is not an HTML element. 

<!DOCTYPE html>
<html>

The root element that contains the entire HTML document.

<html lang="en">...</html>
<head>

Contains page information and resource links that are not displayed as the main page content. 

<head>...</head>
<title>

Sets the page title shown in the browser tab and often used by search engines. 

<title>My Website</title>
<body>

Contains the visible page content, such as headings, paragraphs, images, and links. 

<body>...</body>
A typical page starts with <!DOCTYPE html>, followed by <html>, then <head> and <body>.

02. Metadata & resources

Information about the document and external resources.

<meta>

Provides metadata such as character encoding, page description, and responsive viewport settings. 

<meta charset="UTF-8">
<meta name="viewport" content="width=device-width, initial-scale=1.0">
<link>

Connects an external resource, commonly a CSS stylesheet or favicon. 

<link rel="stylesheet" href="style.css">
<style>

Contains CSS rules written inside the HTML document.

<style>
  p { color: navy; }
</style>
<script>

Embeds or links JavaScript code.

<script src="app.js" defer></script>
<base>

Sets the base URL used for relative URLs in the document. Place it in the head. 

<base href="https://example.com/">
<noscript>

Displays fallback content when scripting is disabled or unsupported. 

<noscript>Enable JavaScript for full features.</noscript>

03. Headings & text blocks

Elements used to organize written content.

<h1>

The main heading of a page or section. Use heading levels according to document structure. 

<h1>Main heading</h1>
<h2>

A second-level heading, usually a subsection under an h1.

<h2>Section heading</h2>
<h3> – <h6>

Third- through sixth-level headings for nested sections.

<h3>Subsection</h3>
<h4>Smaller section</h4>
<p>

Defines a paragraph of text.

<p>This is a paragraph.</p>
<br>

Creates a line break. It is a void element and has no closing tag. 

First line<br>Second line
<hr>

Represents a thematic break between sections, often displayed as a horizontal line. 

<p>Topic one</p>
<hr>
<p>Topic two</p>
<pre>

Displays preformatted text while preserving spaces and line breaks. 

<pre>
  Keep this spacing
</pre>
<blockquote>

Represents an extended quotation from another source.

<blockquote cite="https://example.com">
  A quoted passage.
</blockquote>

04. Inline text & meaning

Elements that add meaning or formatting within text.

<strong>

Marks text as strongly important; browsers usually display it in bold. 

<strong>Important notice</strong>
<em>

Emphasizes text; browsers usually display it in italics.

<em>Pay attention</em>
<b>

Draws attention to text without implying extra importance. 

<b>Keyword</b>
<i>

Marks text in an alternate voice or mood, commonly displayed in italics. 

<i>Scientific term</i>
<u>

Marks text with a non-textual annotation, commonly displayed with an underline. 

<u>Annotated text</u>
<s>

Represents content that is no longer accurate or relevant. 

<s>Old price: Rs. 500</s>
<del> / <ins>

Mark deleted and inserted text, respectively.

<del>Old text</del>
<ins>New text</ins>
<mark>

Highlights text relevant to the current context.

<mark>Search result</mark>
<small>

Represents side comments or fine print, such as copyright text. 

<small>Terms apply.</small>
<sub>

Displays subscript text, commonly used in chemical formulas. 

H<sub>2</sub>O
<sup>

Displays superscript text, commonly used for powers or footnotes. 

x<sup>2</sup>
<code>

Represents a fragment of computer code.

<code>console.log("Hi")</code>
<kbd>

Represents user input, usually from a keyboard.

Press <kbd>Ctrl</kbd> + <kbd>S</kbd>
<samp>

Represents sample output from a computer program.

<samp>File saved.</samp>
<var>

Represents a variable in a mathematical expression or programming context. 

<var>x</var> = 10
<abbr>

Represents an abbreviation; its title attribute can provide the full form. 

<abbr title="HyperText Markup Language">HTML</abbr>
<cite>

Identifies the title of a creative work.

<cite>A Brief History of Time</cite>
<q>

Represents a short inline quotation.

<q>Learning never stops.</q>
<dfn>

Marks the defining instance of a term.

<dfn>HTML</dfn> structures web content.
<time>

Represents a time or date in a machine-readable format.

<time datetime="2026-11-15">15 Nov 2026</time>
<data>

Links visible content to a machine-readable value.

<data value="SKU-101">Blue shirt</data>
<span>

A generic inline container used for styling or scripting.

<span class="highlight">Text</span>
<bdi>

Isolates text whose direction may differ from surrounding text. 

<bdi>اسم المستخدم</bdi>
<bdo>

Overrides the text direction.

<bdo dir="rtl">Hello</bdo>
<wbr>

Suggests a possible line-break location in a long word or URL. 

verylongword<wbr>continues
<ruby> / <rt> / <rp>

Provide ruby annotations, often pronunciation guides for East Asian text. 

<ruby>漢 <rt>kan</rt></ruby>

05. Links

Connect pages and provide navigation.

<a>

Creates a hyperlink to another page, file, email address, or location. 

<a href="https://example.com">Visit site</a>
<nav>

Groups major navigation links for a website or page.

<nav>
  <a href="/home">Home</a>
</nav>

06. Lists

Organize related items in different list formats.

<ul>

Creates an unordered, usually bulleted, list.

<ul>
  <li>HTML</li>
  <li>CSS</li>
</ul>
<ol>

Creates an ordered list, usually numbered.

<ol>
  <li>Plan</li>
  <li>Build</li>
</ol>
<li>

Defines an item inside an ordered or unordered list.

<li>List item</li>
<dl>

Contains a description list of terms and their descriptions. 

<dl>...</dl>
<dt>

Specifies a term or name in a description list.

<dt>HTML</dt>
<dd>

Provides the description or value for a term in a description list. 

<dd>Markup language for web pages.</dd>

07. Images & media

Embed visual, audio, and video content.

<img>

Embeds an image. Always provide meaningful alt text when the image conveys information. 

<img src="photo.jpg" alt="A mountain view">
<picture>

Offers multiple image sources so the browser can select the most suitable one. 

<picture>
  <source media="(max-width:600px)" srcset="small.jpg">
  <img src="large.jpg" alt="Landscape">
</picture>
<source>

Specifies alternative media files for picture, audio, or video elements. 

<source src="movie.mp4" type="video/mp4">
<audio>

Embeds audio content, often with browser playback controls. 

<audio controls src="audio.mp3"></audio>
<video>

Embeds a video player in the page.

<video controls width="320">
  <source src="movie.mp4" type="video/mp4">
</video>
<track>

Adds timed text tracks such as subtitles or captions to audio and video. 

<track kind="subtitles" src="captions.vtt" srclang="en" label="English">
<figure>

Groups self-contained content such as an image, diagram, or code example. 

<figure>...</figure>
<figcaption>

Provides a caption for its parent figure.

<figcaption>Mountain at sunrise</figcaption>
<map>

Defines an image map containing clickable areas.

<map name="workmap">...</map>
<area>

Defines a clickable region inside an image map.

<area shape="rect" coords="0,0,80,80" href="page.html" alt="Area">
<iframe>

Embeds another HTML page or external content inside the current page. 

<iframe src="https://example.com" title="Example"></iframe>
<embed>

Embeds external content, such as a supported document or plugin resource. 

<embed src="file.pdf" type="application/pdf">
<object>

Represents an external resource, which may be an image, nested browsing context, or resource handled by a plugin. 

<object data="file.pdf" type="application/pdf"></object>
<canvas>

Provides a drawing area that JavaScript can use for graphics and animations. 

<canvas id="chart" width="300" height="150"></canvas>
<svg>

Embeds scalable vector graphics, such as icons and diagrams. 

<svg viewBox="0 0 100 100">
  <circle cx="50" cy="50" r="40" />
</svg>

08. Tables

Display structured data in rows and columns.

<table>

Creates a table for structured tabular data.

<table>...</table>
<caption>

Provides a title or description for a table.

<caption>Student marks</caption>
<thead>

Groups the header rows of a table.

<thead>...</thead>
<tbody>

Groups the main body rows of a table.

<tbody>...</tbody>
<tfoot>

Groups footer rows, often containing totals or summaries.

<tfoot>...</tfoot>
<tr>

Defines a row in a table.

<tr>...</tr>
<th>

Defines a header cell in a table.

<th scope="col">Name</th>
<td>

Defines a standard data cell in a table.

<td>Aayan</td>
<col>

Specifies properties for one or more columns in a colgroup. 

<col span="2">
<colgroup>

Groups columns so shared properties can be applied.

<colgroup><col span="2"></colgroup>

09. Forms & user input

Collect information and create interactive controls.

<form>

Groups controls used to submit user-provided information.

<form action="/submit" method="post">...</form>
<input>

Creates an input control. Its type attribute determines the kind of data or control. 

<input type="text" name="username">
<input type="checkbox">
<label>

Provides a text label for a form control. Connect it using for and the control's id. 

<label for="email">Email</label>
<input id="email" type="email">
<textarea>

Creates a multi-line text input field.

<textarea rows="4" cols="30"></textarea>
<button>

Creates a clickable button.

<button type="submit">Send</button>
<select>

Creates a drop-down list of options.

<select name="city">...</select>
<option>

Defines a choice inside a select, optgroup, or datalist.

<option value="karachi">Karachi</option>
<optgroup>

Groups related options inside a select menu.

<optgroup label="Cities">...</optgroup>
<fieldset>

Groups related form controls.

<fieldset>...</fieldset>
<legend>

Provides a caption for a fieldset.

<legend>Personal details</legend>
<datalist>

Provides suggested options for an input control.

<input list="browsers">
<datalist id="browsers">...</datalist>
<output>

Displays the result of a calculation or user action.

<output name="result">42</output>
<progress>

Shows the completion progress of a task.

<progress value="70" max="100">70%</progress>
<meter>

Displays a scalar measurement within a known range, such as disk usage. 

<meter min="0" max="100" value="65">65%</meter>

10. Semantic layout

Describe the meaning and purpose of page regions.

<header>

Represents introductory content or a group of navigation links for a page or section. 

<header>Logo and heading</header>
<main>

Contains the dominant content of the document. Normally use one main element per page. 

<main>Page content</main>
<footer>

Represents footer information for a page or section, such as author or copyright details. 

<footer>© 2026 My Website</footer>
<section>

Groups thematically related content, usually with a heading. 

<section>
  <h2>About us</h2>
</section>
<article>

Represents self-contained content that could stand independently, such as a blog post. 

<article>Blog post</article>
<aside>

Contains indirectly related content, such as a sidebar or note. 

<aside>Related links</aside>
<address>

Provides contact information for a person, organization, or article. 

<address>contact@example.com</address>

11. Interactive elements

Native HTML elements for disclosure and dialog interfaces.

<details>

Creates a disclosure widget that users can open and close. 

<details>...</details>
<summary>

Provides the visible label for a details disclosure widget. 

<details>
  <summary>Read more</summary>
  Extra information.
</details>
<dialog>

Represents a dialog box or other interactive component, such as a modal. 

<dialog open>Hello!</dialog>
<template>

Holds HTML that is not rendered immediately and can be cloned using JavaScript. 

<template id="card">
  <article>...</article>
</template>
<slot>

Defines a placeholder inside a web component's shadow tree. 

<slot name="title"></slot>

12. Other useful elements

Additional elements for language, annotations, and embedded content.

<div>

A generic block-level container used for grouping and styling content when no semantic element fits. 

<div class="container">Content</div>
<data>

Associates visible content with a machine-readable value.

<data value="42">Forty-two</data>
<ruby>

Groups ruby annotations used to show pronunciation or other annotation text. 

<ruby>漢<rt>kan</rt></ruby>
<noscript>

Defines fallback content for users whose browser does not support or has disabled scripting. 

<noscript>JavaScript is disabled.</noscript>
Study tip: Learn the purpose of an element, not just its appearance. For example, use <strong> for importance, not merely to make text bold; use <nav> for navigation and <main> for the page's main content.
